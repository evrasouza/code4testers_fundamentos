# 💎 Ruby Fundamentals for Testers

Study repository focused on **programming fundamentals with Ruby**, created as part of my learning path in test automation.

The goal of this project was to strengthen basic programming concepts commonly used when building automated tests.

## 🎯 Topics Covered

The repository contains practical examples covering:

- Variables and data types
- Arrays
- Hashes
- Operators
- Loops
- Methods
- Basic programming logic
- Simple exercises with Ruby

## ▶️ Running the Examples

Make sure Ruby is installed:

```bash
ruby -v
```

Then execute any example directly:

```bash
ruby arrays.rb
```

or:

```bash
ruby loops.rb
```
